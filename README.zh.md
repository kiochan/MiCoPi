[English](README.md) · [简体中文](README.zh.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

面向动漫与漫画创作者的轻量原生绘画软件，使用 Rust 编写，优先保证绘画响应，同时提供可扩展、面向 AI 的执行核心。

目前支持 **Windows 10/11 x64**。桌面工作台使用 **egui + egui_dock** 和 OpenGL，数位笔输入使用 Windows Ink。项目仍处于早期开发阶段。

**0.21.0：** 新增[可验证的事件回放](docs/replay.md)。记录笔触压感、图层和插件操作，支持时间轴播放、SHA-256 完整性校验、工程内保存历史，以及导出回放文件和 PNG 帧序列。

新增[原子操作组](docs/atomic-operations.md)：失败时回滚整组画布修改，只提交一条组级事件。MCRPLY02 使用元数据差分、像素块引用和 XOR 压缩，仍支持旧版回放。

![MiCoPi 实际工作台，截图为英语界面](docs/screenshots/workbench.png)

工具栏与画布均为可跨显示器移动的独立系统窗口，可浮动、四向停靠或组成标签页。各功能插件拥有自己的窗口声明与界面源码，注册的 action 均可搜索和配置快捷键。参见 [Plugin Windows](docs/plugin-windows.md)。

笔刷面板新增带容差、扩展/收缩及羽化的连通/全层同色填充、支持重复和镜像的线性/径向渐变，以及压感动态和曲线预览。详见[绘画工具](docs/painting-tools.md)。

笔刷与橡皮支持独立的**流量**和可选的**单笔不透明度限制**，并提供叠色马克笔预设。默认流量 100%／叠加模式保留原有绘画效果。集中设置、节点、MCP 和 headless 共用这些参数。功能范围与验证状态见[笔刷不透明度与流量](docs/stroke-opacity.md)。

[解析笔尖](docs/brush-tips.md)支持圆形／椭圆和方形／矩形、25–100% 圆度及固定的顺时针角度，光标显示对应的名义轮廓。笔刷／橡皮、集中默认设置、预设、节点、MCP 和 headless 共用这些值；默认圆形保留旧版像素结果与回放格式。本次源码功能及有界的合成成本测试等待 CI 验证，采样／纹理笔尖和倾斜动态仍在计划中。

[用户笔刷预设](docs/brush-presets.md)保存完整的笔刷／橡皮标量参数，同时保留前景色与背景色。“我的笔刷”提供搜索、保存／更新、重命名、删除及有界的纯数据导入／导出；工作流、MCP 和 headless 共用精确的提供者校验与缓存状态。内置预设保持只读。本次源码功能等待 CI 验证，采样笔尖与纹理仍在计划中。

画布尺寸调整、精确裁剪、整幅画布 90°／180° 旋转与翻转会保留图层、节点身份和选区，并支持撤销与可验证回放。单层 90° 旋转保持画布尺寸，超出边框的像素会被裁剪。**图像大小（Ctrl+Alt+I）**支持像素、毫米和英寸输入，可等比缩放全部图层与选区，支持最近邻、双线性和面积平均采样。只读规划会显示最终尺寸及缓冲区成本，并保留精确密度；面积平均可保留缩小时的细线覆盖度。修剪功能可预览透明或角落颜色边缘，按所选方向裁剪所有图层，并支持撤销。参见[画布编辑](docs/canvas-editing.md)。

**移动工具（V）**提供轮廓拖动预览，松开后统一提交。可以移动当前栅格图层及其关联蒙版、独立的原始栅格蒙版、无栅格蒙版文档中的选中像素，或仅移动选区轮廓。自动模式优先当前绘画蒙版；`mask_id` 可独立于活动画层指定稳定目标。方向键与 Shift+方向键步长可在集中设置中搜索配置。超出画布的内容会被裁切，通过一次撤销恢复。操作也可通过节点、MCP 和 headless 执行。详见[移动与微移](docs/canvas-editing.md#move-and-nudge)及[栅格所有者移动](docs/raster-owner-movement.md)。

**自由变换（Ctrl+T）**支持数值输入、鼠标／笔拖动平移、缩放、斜切、旋转、翻转与中心点，提供可取消的缓存像素预览，一次确认对应一次撤销和事件。相同原生动作可通过节点、MCP 和 headless 执行。超出画布的像素会被裁切；**Ctrl+Shift+T** 重复已保存的矩阵，**Ctrl+Alt+Shift+T** 复制并重复变换；记录随项目、撤销与回放保留。边中点的菱形手柄可调整斜切，透视角点可独立拖动，并保持相同的撤销、重复与回放机制。上述复制／透视快捷键保留原有单目标规则；[所有者／联动仿射范围](docs/owner-affine.md)会携带关联原始蒙版、保留选区，并按捕获的明确 ID 重复。详见[自由变换](docs/canvas-editing.md#free-transform)。

[统一插件系统](docs/plugin-system.md)在设置和自动化接口中公开版本、兼容性、依赖与加载状态。启用/禁用规划会处理依赖，保存后重启生效；插件可提供互不干扰、支持热加载的语言包。
**新建画布（Ctrl+N）**支持可配置的插画、方形、A4 和 B5 预设，可选择初始背景像素、像素／毫米／英寸尺寸和物理分辨率，并通过共享的只读规划在创建前确认最终像素尺寸。分辨率元数据随项目、撤销和回放保存，不会重采样像素。参见[画布创建说明](docs/document-setup.md)。


[PNG 密度](docs/png-density.md)在导入、导出、项目和回放 PNG 中保留横纵密度与单位；物理尺寸未知时会明确标示。设置分辨率会替换导入密度，不会重采样像素。

[PNG 导出尺寸](docs/export-sizing.md)支持像素、毫米、英寸和百分比、显式预览及仅用于输出的 PPI 设置。原生采样处理合成图，不修改源图层和历史；导出事件记录文件摘要。

[颜色混合模式](docs/blend-modes.md)为图层、隔离图层组和混合节点提供 26 种模式，包含加深／减淡、对比度以及色相／饱和度／颜色／明度类别。滚动菜单按 Photoshop 常用类别排列，不支持的模式仍会显示并禁用。原有八种模式的 ID 和像素结果保持兼容，共享 API 可查询当前合成器支持的模式。

## 主要理念

**绘画优先，行为由插件承载，人与自动化共用同一个执行核心。**

逐点输入采用强类型接口，保留压感、防抖和局部更新。插件、MCP 与 headless 通过带 schema 的 action 和公开状态操作同一个 Session。图像节点非破坏式合成画布；操作节点只有明确运行时才执行。

“AI-ready”代表可发现、可检查、可验证的集成契约，不代表必须联网或内置云端助手。配图与详细说明见英文[设计理念](docs/philosophy.md)、[文档索引](docs/README.md)、[开发路线图](ROADMAP.md)和[目录规划](docs/project-structure.md)。技术文档以英语为准。

## 当前功能

- 独立 DLL 实现画笔、橡皮、吸管、抓手和缩放。
- Windows Ink 压感、压力曲线、防抖和笔刷轮廓光标。
- HSV 色环、RGB 控件、色板和笔刷预设。
- 图层显隐、透明度、透明度锁定、颜色填充、混合模式和分块撤销/重做。
- 可停靠、浮动、分组的标签面板；间距、尺寸、主题和快捷键可配置。
- 集中搜索设置、JSON 编辑、命令面板和快捷键录制。
- PNG 透明导出、PNG/JPEG/BMP 导入和 `.mcp` 工程文件。
- 图像节点与图层栈联动，支持逐层滤镜及自由合成；插件可注册 action/状态流程节点。
- JSONL 批处理、MCP stdio，以及连接正在运行的 GUI。
- 统一插件清单、依赖感知的设置和按插件隔离的语言包。

图层支持重命名、复制、重排和删除，以及精确翻转、旋转 180° 和整数偏移。详见[图层编辑](docs/layer-editing.md)。

图层支持像素／位置锁定、颜色标签，以及共享的名称、可见性和锁定筛选，并支持撤销、项目保存与可验证回放。原生写入权限保护锁定目标，同时保留取色、拖动和缩放。

Ctrl／Shift 可多选图层，绘画仍作用于活动图层。通过明确的稳定 ID，可以批量修改属性、复制、删除、排序或执行精确像素操作，整批对应一次撤销／重做和一个可验证结果。节点、MCP 和 headless 可使用相同命令与选择状态。

[图层链接](docs/layer-links.md)可保存线稿、上色等图层的关联，使整层移动和方向键微移一起生效。图层面板提供链接／取消链接按钮和链条标记，绘画仍只作用于活动目标。明确的目标数组携带各自关联蒙版，在内存限额内统一撤销和回放；命令与状态节点同样支持 MCP、headless。[联动仿射自由变换](docs/owner-affine.md)会捕获明确的目标与统一矩阵，重复操作保留原 ID；复制重复与透视仍限于原有支持范围。对齐／分布仍在计划中，本次所有者变换的运行验证等待 CI。

**Ctrl+J** 通过选区拷贝新建图层（无选区时复制整层）；**Ctrl+Shift+J** 通过选区剪切新建图层。两者均支持一次撤销，且不修改剪贴板。

合并图层（Ctrl+E）在多选时合并选中的栅格层，单选时向下合并。仍支持合并可见图层（Ctrl+Shift+E）、盖印可见图层（Ctrl+Alt+Shift+E）和保留透明画布的拼合图像。详见 [Layer editing](docs/layer-editing.md)。

[仅合并选中图层](docs/selected-merge.md)支持不连续及跨组目标，保留未选中图层的原始缓冲区和所有文件夹。它在透明背景上烘焙选中内容，因此与外部背景、堆叠顺序的交互可能改变。只读计划及可选的非模态检查窗口展示插入位置和将被移除的隐藏图层；通过节点、MCP 和 headless 显式指定稳定 ID 执行时，同样支持单步撤销与可验证回放。Ctrl+E 仍直接执行，原有显式向下合并快捷键保持兼容。

[图层组](docs/layer-groups.md)支持嵌套可见性、不透明度、隔离或[穿透合成](docs/pass-through.md)、整组操作及实际合成节点视图。穿透模式让子图层与父级背景混合，再用组不透明度统一控制变化，并保留原有隔离混合模式。Ctrl+G 可将同级选中图层分组；绘画仍作用于活动栅格层。合并组仅接受隔离目标，内部可包含穿透子组；组中的合并可见会保留隐藏分支和文件夹。命令、项目、原子历史和回放与 MCP／headless 共用。

当前每个 Session 只支持一份文档；尚无 Wintab、画布外图层内容存储、剪贴蒙版或水彩引擎。原生 DLL 与宿主在同一进程中执行。

[调整图层](docs/adjustment-layers.md)是真正影响下方合成结果的非栅格堆栈项，提供五种已注册滤镜、保持透明度的正常混合、不透明度及独立 A8 蒙版。根堆栈、隔离组与穿透组共享命令、撤销和可验证结果；检查调整属性不会切换活动绘画目标，组复制／删除会保留所有者关系。色阶与曲线调整图层已接入，更多混合方式仍在计划中，本次源码功能等待 CI 验证。

[图层对齐与分布](docs/layer-arrangement.md) 使用明确捕获的栅格图层 ID，支持边缘对齐、居中、中心分布及画布对齐。位置取决于原始笔迹边界，关联蒙版随图层移动，一次操作对应一次撤销与已验证结果。只读计划保留当前接触状态，节点、MCP 与无界面客户端共用命令；运行验证等待 CI。

[栅格蒙版编辑](docs/raster-mask-editing.md)现支持图层／组 A8 蒙版、压感笔刷与橡皮擦、防抖、非破坏性密度／羽化、选区转换，以及将蒙版应用到栅格图层的原始透明度。11 个蒙版命令和公开状态共用于界面、工作流节点、MCP 和 headless，并保留分块撤销及可验证存储。[文档整体几何操作](docs/mask-canvas-geometry.md)会随画布一起调整边界、旋转、翻转、重采样和裁切所有原始蒙版，包括隐藏、禁用和未链接蒙版。共享只读计划分别显示蒙版开销、接触状态和原生能力；应用一次产生一个可撤销编辑。[单图层所有者复制／删除](docs/mask-owner-editing.md)现会携带精确的原始蒙版，使用新 ID、明确的绘画目标规则及一个复合撤销／事件结果。[组创建与层级移动](docs/mask-group-editing.md)会保留所有现有所有者、原始蒙版及绘画目标，并共享一个结构性撤销／事件结果和 schema 绑定。[删除组及其内容](docs/mask-group-delete.md)只会移除被消耗所有者的蒙版，并提供明确的绘画目标／选择回退、必需的结果 ID 数组和一个复合撤销／事件结果。[组／子树复制](docs/mask-group-duplicate.md)会使用按规则分配的新 ID 和独立原始缓冲区复制嵌套所有者，并提供绘画目标映射、类型化结果数组及一个复合撤销／事件结果。[栅格所有者整数移动](docs/raster-owner-movement.md)会在一次编辑中携带关联蒙版，或仅移动指定原始蒙版。[所有者仿射自由变换](docs/owner-affine.md)增加明确的栅格目标集合与独立原始蒙版变换。组蒙版移动、选中像素转移、有蒙版文档中的选区轮廓仿射变换（仍可整数移动轮廓）、解组、批量编辑、选区复制／剪切转移、合并、剪贴板修改和组蒙版应用仍受保护性限制；完整集成仍在计划中。

[选区命令](docs/selections.md)支持矩形、椭圆、多边形与组合模式，笔刷和像素操作遵守选区，并支持撤销和回放。全选、取消、重选和反选支持可配置的 PS 快捷键；工具栏已提供矩形／椭圆框选和自由／多边形套索，预览可取消；已提供 [Session 内部剪贴板](docs/clipboard.md)复制、剪切与粘贴命令；已接入 Windows PNG/DIB 图片剪贴板和 PS 复制／剪切／粘贴快捷键；受测试环境权限限制，原生跨软件往返尚待验证。

魔棒（**W**）支持容差、连续区域和合并取样，并提供扩大选区／选取相似颜色按钮；同一套命令也可通过参数表单及自动化执行。 选区默认值可在统一设置中心搜索配置，并保存到 `settings.json`。 选区还支持通过原生动作扩展、收缩、羽化和平滑。

## 构建与运行

需要 Rust 1.88+、Visual Studio C++ Build Tools 和 Windows SDK。

```powershell
.\scripts\build.ps1 -PluginsOnly
cargo run --release --locked
.\scripts\build.ps1 -Test
```

运行 `dist/MiCoPi.exe`，保留同目录的 `plugins/`、`locales/` 和 `licenses/`。最终用户无需安装 Rust。项目本地便携工具链的用法见英文[开发指南](docs/development.md)。

```powershell
New-Item -ItemType Directory -Force target/example-output | Out-Null
.\dist\micopi-cli.exe run examples/automation/draw.jsonl
.\dist\micopi-cli.exe actions
.\dist\micopi-cli.exe mcp
```

默认 MCP 使用独立画布；通过 `mcp --attach <profile>/session.json` 可连接现有 GUI。示例按用途归类，见 [examples](examples/README.md)。

## 界面语言

默认语言为英语，支持简体中文、日语和韩语。按 **Ctrl+,** 打开设置，搜索 `ui.language`，选择语言并保存。切换会立即预览；关闭未保存的设置会恢复上次保存的值。

```json
{"version":1,"ui":{"language":"zh-CN"}}
```

语言不会改变 action ID、配置键、节点端口、文件路径或画布像素。详见英文[多语言说明](docs/localization.md)。

仅英语内嵌在程序中。其他语言从程序目录的 `locales/` 加载，配置目录中的 `locales/` 可覆盖默认翻译。修改 JSON 后无需编译或重启；文件错误时保留上一版有效翻译。使用 `--locales-dir <目录>` 可更换基础语言包目录。

## 扩展 MiCoPi

[Quick tools 示例](examples/plugins/quick-tools/manifest.json)包含笔刷预设、宏和多语言按钮面板。将整个插件包复制到插件目录后重启；用 `plugins.list` 查看状态、诊断和功能归属，用只读的 `plugins.plan` 预览依赖变化。

像素算法通过[原生 C ABI SDK](docs/native-plugins.md)扩展。功能界面源码随宿主编译；更换 DLL 或修改功能声明后需重启。宿主统一提供执行、文档历史和窗口生命周期。详见[插件系统](docs/plugin-system.md)和[插件窗口](docs/plugin-windows.md)。

## 目录与贡献

`src/` 保存宿主与界面，`plugins/` 保存可安装插件包和独立算法，`crates/plugin-api/` 保存 ABI SDK。文档、截图、示例和工具分别位于 `docs/`、`docs/screenshots/`、`examples/` 和 `scripts/`。构建、发行产物与个人作品不进入 Git。

请阅读英文[贡献指南](CONTRIBUTING.md)、[架构说明](docs/architecture.md)和[变更记录](CHANGELOG.md)。英语 README 是项目概述的基准，三个翻译版本与其保持一致。

编码代理还应阅读 [AGENTS.md](AGENTS.md)。遵循维护者指定的 Git 流程；当前维护者委托的工作直接在 `main` 按功能提交。仅在明确要求时推送，不提交构建产物或个人配置。
