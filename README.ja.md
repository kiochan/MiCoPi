# MiCoPi

[トーンカーブのソースノード](docs/curves.md)は連動／自由グラフ、マスターと R/G/B 制御点、ネイティブキャッシュ、Undo、プロジェクトと検証可能な結果に対応します。CI 検証待ちで、カーブ調整レイヤーも同じ契約を共有し、共通カーブ操作はドラッグと数値編集に対応し、[ヒストグラム照会](docs/histograms.md)は上限付きの合成／生レイヤー統計を提供し、レベル／カーブ編集では手動更新の共有グラフに適用済み合成画像／生レイヤーの範囲を明示します。UI 検証とノード入力統計は未完了です。

[レベル補正](docs/levels.md) は連動／自由ソースグラフと下の画像に作用する調整レイヤーに対応し、マスター／R／G／B 入出力コントロール、ネイティブチャンネルキャッシュ、マスク、Undo、プロジェクトと検証可能な再生を共有します。チャンネル統合テストは CI 検証待ちです。

[English](README.md) · [简体中文](README.zh.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

アニメ・マンガのイラスト制作に向けた、Rust 製の軽量なネイティブペイントアプリです。描画の応答性を重視し、拡張可能で AI と連携できる実行コアを備えています。

現在は **Windows 10/11 x64** に対応しています。デスクトップ UI は **egui + egui_dock** と OpenGL、ペン入力は Windows Ink を使用します。開発初期のプロジェクトです。

**0.21.0:** [検証可能なイベント再生](docs/replay.md)を追加しました。筆圧、レイヤー、プラグイン操作を記録し、タイムライン再生、SHA-256 検証、プロジェクト内の履歴保存、記録ファイルと PNG 連番の書き出しに対応します。

[アトミック操作グループ](docs/atomic-operations.md)を追加しました。失敗時に変更を戻し、グループ全体を一つのイベントとして記録します。MCRPLY02 はメタデータ差分、タイル参照と XOR 圧縮を使用し、旧形式の読み込みも維持します。

![実際の MiCoPi ワークベンチ。画像は英語表示です](docs/screenshots/workbench.png)

ツールバーとキャンバスは別のモニターへ移動できる独立した OS ウィンドウで、フロート、四方向のドッキング、タブ化に対応します。各機能プラグインがウィンドウ定義と UI ソースを所有し、登録したアクションは検索とショートカット設定が可能です。[Plugin Windows](docs/plugin-windows.md) を参照してください。

ブラシパネルから拡張・縮小・ぼかし対応の連続領域・レイヤー全体の同色塗りつぶし、繰り返し・折り返し対応の線形・放射状グラデーション、筆圧設定とカーブ表示を利用できます。[描画ツール](docs/painting-tools.md)を参照してください。

ブラシと消しゴムは独立した**流量**と任意の**ストロークごとの不透明度制限**に対応し、重ね塗りマーカーのプリセットも利用できます。既定の流量 100%／重ね塗りモードは従来の描画を維持します。検索可能な設定、ノード、MCP、ヘッドレスで共通のパラメーターを使います。対応範囲と検証状況は[ブラシの不透明度と流量](docs/stroke-opacity.md)を参照してください。

[解析的なブラシ先端](docs/brush-tips.md)は円／楕円と正方形／長方形、25–100% の丸み比率、固定の時計回り角度に対応し、カーソルに対応する輪郭を表示します。ブラシ／消しゴム、検索可能な既定設定、プリセット、ノード、MCP、ヘッドレスで同じ値を使い、既定の円は従来の画素と記録を維持します。このソース実装と範囲を限定した合成コスト計測は CI 検証待ちです。サンプル／テクスチャ先端と傾きの動的制御は今後の予定です。

[ユーザーブラシプリセット](docs/brush-presets.md)は前景色と背景色を保ったまま、ブラシ／消しゴムの全スカラーパラメーターを保存します。「マイブラシ」で検索、保存／更新、名前変更、削除、容量制限付きのデータ専用インポート／エクスポートを行えます。正確な提供元の検証とキャッシュ状態はワークフロー、MCP、ヘッドレスで共通です。組み込みプリセットは読み取り専用です。今回のソース実装は CI 検証待ちで、サンプル筆先とテクスチャは今後の予定です。

キャンバスサイズ変更、正確な切り抜き、キャンバス全体の 90°／180° 回転と反転に対応し、レイヤー・ノードの識別情報、選択範囲、取り消しと検証可能な再生を維持します。単一レイヤーの 90° 回転はキャンバスサイズを維持し、枠外の画素を切り取ります。**画像サイズ（Ctrl+Alt+I）**ではピクセル・ミリメートル・インチで入力し、縦横比を固定して全レイヤーと選択範囲をニアレスト、バイリニア、面積平均で拡大・縮小できます。読み取り専用プランで寸法とバッファー容量を確認でき、正確な密度を維持します。面積平均は縮小時の細線の被覆率を保持します。トリミングでは透明または隅の色の余白をプレビューし、選んだ辺で全レイヤーを切り抜けます。取り消しに対応します。[キャンバス編集](docs/canvas-editing.md)を参照してください。

**移動ツール（V）**は輪郭をプレビューし、離すとまとめて確定します。アクティブなラスターレイヤーとリンク済みマスク、独立した元のラスターマスク、マスクのない文書の選択ピクセル、または選択範囲の輪郭を移動できます。自動は描画対象のマスクを優先し、`mask_id` はアクティブレイヤーとは独立した安定 ID を指定します。矢印・Shift+矢印の移動量は検索可能な設定で変更できます。キャンバス外の内容は切り取られ、一回の取り消しで復元できます。ノード、MCP、ヘッドレスも共通です。[移動と微調整](docs/canvas-editing.md#move-and-nudge)と[ラスター所有者の移動](docs/raster-owner-movement.md)を参照してください。

**自由変形（Ctrl+T）**は数値入力とマウス・ペン操作で移動、拡大縮小、ゆがみ、回転、反転、基準点を設定でき、取消可能なキャッシュ済みピクセルプレビューと一回の取り消し・イベントに対応します。同じネイティブ操作をノード、MCP、ヘッドレスでも実行できます。キャンバス外は切り取られ、**Ctrl+Shift+T** で保存した行列を再適用し、**Ctrl+Alt+Shift+T** で複製して再適用します。履歴はプロジェクト、取り消し、リプレイに保持されます。辺のひし形でゆがみを調整でき、遠近変形の角も個別に編集できます。取り消し・繰り返し・リプレイにも対応します。上記の複製・遠近変形は従来の単一対象規則を維持します。[所有者・連動アフィン範囲](docs/owner-affine.md)はリンク済み元マスクを伴い、選択範囲を保持し、保存した明示 ID で繰り返します。[自由変形](docs/canvas-editing.md#free-transform)を参照してください。

[統一プラグインシステム](docs/plugin-system.md)は、バージョン、互換性、依存関係、読み込み状態を設定画面と自動化 API に公開します。有効化・無効化の計画は依存関係を解決し、保存後の再起動で反映されます。プラグイン独自の翻訳ファイルは互いに分離され、ホットリロードできます。
**新規キャンバス（Ctrl+N）**では、イラスト、正方形、A4、B5 の設定可能なプリセット、編集可能な背景ピクセル、ピクセル・ミリメートル・インチの寸法と物理解像度を選べます。共通の読み取り専用プランで、作成前に最終ピクセル寸法を確認できます。解像度メタデータはプロジェクト、取り消し、リプレイに保存され、ピクセルを再サンプリングしません。[キャンバスの作成](docs/document-setup.md)を参照してください。


[PNG 密度](docs/png-density.md)は、読み込み・書き出し、プロジェクト、リプレイ PNG に縦横の密度と単位を保持します。物理サイズが不明な場合は明示し、解像度の設定でピクセルを再サンプリングせずに密度を置き換えます。

[PNG 書き出しサイズ](docs/export-sizing.md)はピクセル、ミリメートル、インチ、割合、明示的なプレビューと出力専用 PPI をサポートします。合成画像をネイティブで処理し、元レイヤーと履歴を保持し、書き出しイベントにファイルハッシュを記録します。

[描画モード](docs/blend-modes.md)はレイヤー、独立合成グループと Blend ノードで 26 種類を共有し、焼き込み／覆い焼き、コントラスト、色相／彩度／カラー／輝度に対応します。スクロールメニューは Photoshop で一般的な分類順に並び、未対応のモードも無効な項目として表示します。従来の 8 モードの ID とピクセル結果を維持し、共通 API で現在のコンポジターの対応状況を確認できます。

## 基本理念

**描画を最優先に。機能はプラグインで実装し、人と自動化は同じ実行コアを使う。**

ペンの各サンプルは型付きインターフェースで処理し、筆圧、手ぶれ補正、部分更新を維持します。プラグイン、MCP、headless は、スキーマ付きアクションと公開状態を通して同じ Session を操作します。画像ノードは非破壊で合成し、操作ワークフローは明示的に実行したときだけ動きます。

AI-ready は、発見・確認・検証できる連携仕様を意味します。クラウドへの常時接続や内蔵 AI アシスタントを必須にはしません。図入りの[設計理念](docs/philosophy.md)、[文書一覧](docs/README.md)、[ロードマップ](ROADMAP.md)、[ディレクトリ構成](docs/project-structure.md)をご覧ください。技術文書の基準言語は英語です。

## 主な機能

- 独立した DLL によるブラシ、消しゴム、スポイト、手のひら、ズーム。
- Windows Ink の筆圧、筆圧カーブ、手ぶれ補正、ブラシ輪郭カーソル。
- HSV カラーホイール、RGB 調整、スウォッチ、ブラシプリセット。
- レイヤー表示、不透明度、透明度保護、単色塗りつぶし、合成モード、タイル単位の取り消しとやり直し。
- ドッキング、フロート、タブグループに対応したパネル。間隔、寸法、テーマ、ショートカットを設定可能。
- 検索できる設定、JSON 編集、コマンドパレット、ショートカットの記録。
- 透明 PNG 書き出し、PNG/JPEG/BMP 読み込み、`.mcp` プロジェクト。
- レイヤー連動の非破壊画像グラフ、レイヤーごとのフィルター、自由合成とプラグイン登録の操作・状態ワークフロー。
- JSONL バッチ、MCP stdio、実行中の GUI への接続。
- 共通のプラグイン一覧、依存関係を考慮する設定、プラグインごとに分離した言語パック。

レイヤーの名前変更、複製、並べ替え、削除と、反転、180° 回転、整数オフセットをサポートします。[レイヤー編集](docs/layer-editing.md)を参照してください。

レイヤーはピクセル・位置ロック、カラーラベル、名前・表示・ロック状態の共通読み取り専用フィルターに対応し、取り消し、プロジェクト、検証可能なリプレイを維持します。ネイティブ書き込み権限でロック対象を保護し、読み取りツールは利用できます。

Ctrl／Shift で複数のレイヤーを選択でき、描画先はアクティブレイヤーのままです。安定した ID を明示するバッチで、プロパティ変更、複製、削除、並べ替え、正確なピクセル編集を実行し、1 回の取り消し／やり直しと検証可能な結果にまとめます。同じコマンドと選択状態をノード、MCP、ヘッドレスから利用できます。

[レイヤーリンク](docs/layer-links.md)は線画・着色などの関係を保存し、レイヤー全体の移動と微調整を連動させます。リンク／解除ボタンとチェーン表示を備え、描画先はアクティブな対象のままです。明示した対象配列と各レイヤーのリンク済みマスクを、メモリ上限内で一度の取り消しと検証可能な結果にまとめます。コマンドと状態ノードは MCP・ヘッドレスにも対応します。[連動アフィン自由変形](docs/owner-affine.md)は明示した対象と一つの行列を保存し、繰り返しも元の ID を使います。複製繰り返し・遠近変形は従来の対応範囲に限定されます。整列・分布は今後の予定で、今回の所有者変形の実行検証は CI 待ちです。

**Ctrl+J** は選択範囲を新規レイヤーへコピーし、選択がなければレイヤー全体を複製します。**Ctrl+Shift+J** は選択範囲を新規レイヤーへ切り取ります。どちらも 1 回で取り消せ、クリップボードは変更しません。

レイヤーを結合（Ctrl+E）は複数選択時に選択ラスターを結合し、単一選択時は下のレイヤーと結合します。表示レイヤーの結合（Ctrl+Shift+E）、表示内容の新規レイヤーへの統合（Ctrl+Alt+Shift+E）、透明部分を保持する画像の統合も利用できます。[Layer editing](docs/layer-editing.md) を参照してください。

[選択レイヤーのみの結合](docs/selected-merge.md)は離れたレイヤーや異なる親グループの対象にも対応し、未選択のバッファーとすべてのフォルダーを保持します。選択内容を透明背景上で焼き込むため、外側の背景や重なりとの関係は変わる場合があります。読み取り専用プランと任意の非モーダル確認ウィンドウで配置や削除される非表示レイヤーを確認でき、明示的な安定 ID による実行はノード、MCP、ヘッドレスで一回の取り消しと検証済み結果を共有します。Ctrl+E は直接実行され、既存の明示的な「下のレイヤーと結合」の割り当ても維持されます。

[レイヤーグループ](docs/layer-groups.md)は階層ごとの表示、不透明度、独立合成または[通過合成](docs/pass-through.md)、サブツリー操作と実際の合成ノード表示に対応します。通過では子レイヤーを親の背景と合成し、グループの不透明度で全体の変化を調整します。独立合成の描画モードは保持されます。Ctrl+G で同じ親の選択レイヤーをまとめ、描画先はアクティブなラスターレイヤーのままです。グループ結合の対象は独立合成グループで、内部に通過グループを含められます。表示レイヤー結合は非表示の枝とフォルダーを保持します。MCP／ヘッドレスも同じコマンド、プロジェクト、アトミック履歴とリプレイを使用します。

現在は Session ごとに文書が 1 つです。Wintab、キャンバス外のレイヤー保存、クリッピングマスク、水彩エンジンは未実装です。ネイティブ DLL はホストと同じプロセス内で実行されます。

[調整レイヤー](docs/adjustment-layers.md)は下側の合成結果に作用する実際の非ラスタースタック項目です。登録済みの5フィルター、アルファを保つ通常の効果補間、不透明度、専用 A8 マスクに対応します。ルート・分離・パススルーの範囲でコマンド、取り消し、検証可能な結果を共有し、プロパティの確認と描画対象を分離します。グループの複製／削除も所有関係を扱います。レベルとカーブ補正は対応済みで、追加の混合方式は今後の予定で、今回のソース実装は CI 検証待ちです。

[レイヤーの整列と分布](docs/layer-arrangement.md) は明示的に取得したラスターレイヤー ID を使い、端・中央の整列、中心の均等配置、キャンバスへの整列を行います。元の筆跡の境界を基準に、リンクされたマスクも一緒に移動し、1 回の操作を 1 回の Undo と検証済み結果にまとめます。読み取り専用の計画は入力中の接触を保持し、ノード・MCP・ヘッドレスも同じコマンドを使います。実行検証は CI 待ちです。

[ラスターマスク編集](docs/raster-mask-editing.md)は、レイヤー／グループの A8 マスク、筆圧と手ぶれ補正に対応したブラシ／消しゴム、非破壊の濃度／ぼかし、選択範囲との変換、ラスターレイヤーの元のアルファへのマスク適用を提供します。11 個のマスクアクションと公開状態を、画面、ワークフローノード、MCP、ヘッドレス実行で共有し、タイル単位の取り消しと検証可能な保存に対応します。[文書全体のジオメトリ操作](docs/mask-canvas-geometry.md)は、非表示・無効・リンク解除済みのマスクも含め、すべての元のマスクをキャンバスとともに再配置・回転・反転・再サンプリング・トリミングします。共通の読み取り専用プランはマスクの容量、接触状態、ネイティブ機能を個別に示し、適用は一つの取り消し可能な編集になります。[単一レイヤー所有者の複製／削除](docs/mask-owner-editing.md)は、元のマスクサンプル、新しい ID、明示的な描画対象の規則を一つの複合取り消し／記録結果として扱います。[グループ作成と階層移動](docs/mask-group-editing.md)は、すべての既存の所有者、元のマスク、描画対象を保持し、一つの構造的な取り消し／記録結果と共通のスキーマバインディングを提供します。[グループと内容の削除](docs/mask-group-delete.md)は、削除対象の所有者のマスクのみを取り除き、明示的な描画対象／選択のフォールバック、必須の結果 ID 配列、一つの複合取り消し／記録結果を提供します。[グループ／サブツリーの複製](docs/mask-group-duplicate.md)は、規定順の新しい ID と独立した元データ用バッファでネストされた所有者を複製し、描画対象のマッピング、型付き結果配列、一つの複合取り消し／記録結果を提供します。[ラスター所有者の整数移動](docs/raster-owner-movement.md)はリンク済みマスクを伴う移動、または元のマスクだけの移動を一つの編集にします。[所有者アフィン自由変形](docs/owner-affine.md)は明示したラスター集合と独立した元マスクに対応します。グループマスク移動、選択ピクセルの転送、マスク付き文書での選択輪郭のアフィン変形（整数移動は対応）、グループ解除、一括編集、選択範囲のコピー／切り取り転送、統合、クリップボード変更、グループマスク適用には保護付きの制限が残り、完全な統合は引き続き計画中です。

[選択範囲コマンド](docs/selections.md)は矩形・楕円・多角形、結合モード、描画のクリッピング、取り消しとリプレイに対応します。全選択・解除・再選択・反転の PS ショートカットを設定できます。ツールバーの長方形・楕円形選択、自由・多角形投げ縄は取消可能なプレビューに対応しています。[Session 内部クリップボード](docs/clipboard.md)のコピー・切り取り・貼り付けコマンドを利用できます。Windows の PNG/DIB 画像クリップボードと PS のコピー・切り取り・貼り付けキーを実装しています。テスト環境の権限制限により、ネイティブの相互運用確認は未完了です。

自動選択（**W**）は許容値・隣接領域・結合画像の参照に対応し、範囲拡張・類似色選択ボタンも利用できます。同じコマンドをパラメータフォームと自動化から実行できます。 選択範囲の既定値は設定センターで検索でき、`settings.json` に保存できます。 選択範囲の拡大・縮小・ぼかし・スムーズ処理もネイティブコマンドから実行できます。

## ビルドと実行

Rust 1.88 以降、Visual Studio C++ Build Tools、Windows SDK が必要です。

```powershell
.\scripts\build.ps1 -PluginsOnly
cargo run --release --locked
.\scripts\build.ps1 -Test
```

`dist/MiCoPi.exe` を起動してください。同じ場所の `plugins/`、`locales/`、`licenses/` が必要です。利用者の環境に Rust は不要です。プロジェクト内のポータブルツールチェーンについては英語の[開発ガイド](docs/development.md)をご覧ください。

```powershell
New-Item -ItemType Directory -Force target/example-output | Out-Null
.\dist\micopi-cli.exe run examples/automation/draw.jsonl
.\dist\micopi-cli.exe actions
.\dist\micopi-cli.exe mcp
```

通常の MCP は独立したキャンバスを使います。`mcp --attach <profile>/session.json` で既存の GUI に接続できます。用途別のサンプルは [examples](examples/README.md) にあります。

## 表示言語

既定は英語で、簡体字中国語、日本語、韓国語に対応しています。**Ctrl+,** で設定を開き、`ui.language` を検索して言語を選び、保存してください。変更はすぐにプレビューされ、未保存のまま閉じると最後に保存した値に戻ります。

```json
{"version":1,"ui":{"language":"ja"}}
```

言語を切り替えてもアクション ID、設定キー、ノード端子名、ファイルパス、キャンバスの画素は変わりません。詳細は英語の[ローカライズガイド](docs/localization.md)を参照してください。

英語のみ実行ファイルに埋め込みます。他の言語は実行ファイルと同じ場所の `locales/` から読み込み、設定ディレクトリの `locales/` で上書きできます。JSON の変更は再ビルド・再起動なしで反映され、不正な編集時は直前の有効な翻訳を維持します。`--locales-dir <directory>` で基本カタログの場所を変更できます。

## MiCoPi の拡張

[Quick tools サンプル](examples/plugins/quick-tools/manifest.json)にはブラシプリセット、マクロ、多言語ボタンパネルが含まれます。パッケージ全体をプラグインディレクトリへコピーして再起動してください。`plugins.list` で状態・診断・機能の所有者を確認し、読み取り専用の `plugins.plan` で依存関係の変更を確認できます。

画素処理は[ネイティブ C ABI SDK](docs/native-plugins.md)で拡張します。機能 UI のソースはホストと一緒にコンパイルし、DLL の交換や機能定義の変更には再起動が必要です。実行、文書履歴、ウィンドウのライフサイクルはホストが管理します。[プラグインシステム](docs/plugin-system.md)と[プラグインウィンドウ](docs/plugin-windows.md)を参照してください。

## 構成と貢献

`src/` はホストと UI、`plugins/` はインストール可能なパッケージと独立したアルゴリズム、`crates/plugin-api/` は ABI SDK です。文書、画像、サンプル、開発ツールは `docs/`、`docs/screenshots/`、`examples/`、`scripts/` に分かれています。ビルド結果、配布ファイル、個人の作品は Git に含めません。

英語の[貢献ガイド](CONTRIBUTING.md)、[アーキテクチャ](docs/architecture.md)、[変更履歴](CHANGELOG.md)をご覧ください。英語 README を基準とし、翻訳版も同じ機能と制約を説明します。

コーディングエージェントは [AGENTS.md](AGENTS.md) も参照してください。メンテナー指定の Git 手順に従い、現在の委託作業は `main` に機能単位でコミットします。プッシュは明示的な依頼時のみ行い、ビルド成果物や個人設定はコミットしません。
