These are actual application captures, not interface mockups. Current images come from the isolated GUI smoke checks for MiCoPi 0.19. Documentation deliberately reuses stable filenames so image updates do not require changing every guide.

The checkerboard and pen strokes are generated by the same DLL/action pipeline used in runtime parity tests. They are demonstration content rather than a benchmark or a claim about an artist's work.

Run `scripts/smoke-runtime.py`, `scripts/smoke-workflows.py` and `scripts/smoke-localization.py` to generate new captures under ignored `target/test-output/`. Inspect the results before promoting selected files here. Do not commit entire test-output folders.

Older screenshots live in [archive](archive/README.md) for historical reference. They do not represent the current interface and are omitted from portable release screenshots.
