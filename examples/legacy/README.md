# Historical Workspace Examples

[workspace.ini](workspace.ini) and [panels-tabs.ini](panels-tabs.ini) are retained for the earlier GDI workspace and regression reference. They are not the current egui dock format.

Current settings use `settings.json`; current dock trees, tab groups and floating rectangles use `workspace.egui.json`. See the [User Guide](../../docs/user-guide.md) before migrating personal configuration.
